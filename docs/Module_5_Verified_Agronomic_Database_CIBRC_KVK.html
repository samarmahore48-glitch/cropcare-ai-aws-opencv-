Production Blueprint · Module 5

5. Verified Agronomic Database (CIBRC/KVK)

Target Goal: Ensure all pesticide, fungicide, and bio-agent remedies strictly adhere to government-registered guidelines (CIBRC / ICAR / State Agricultural Universities).

Warning: Never allow an LLM or unverified AI model to invent pesticide dosages. Chemical misuse can destroy crops, pollute groundwater, and violate the Insecticides Act, 1968. Every treatment recommendation must pull from a verified database.

Step 1: CIBRC-Compliant Database Table Structure

Field Type Description & Example
target_crop VARCHAR(50) Crop name (e.g. Tomato)
target_disease VARCHAR(100) Pathogen or pest (e.g. Early Blight)
chemical_type VARCHAR(30) Organic, Biological, or Chemical
active_ingredient VARCHAR(100) Copper Oxychloride 50% WP
dose_per_acre VARCHAR(50) 500 - 600 grams
dilution_water_liters INTEGER 200 Liters / Acre
pre_harvest_interval_days INTEGER Waiting period before harvest (e.g. 3 days)
banned_status BOOLEAN Must be FALSE (checked against CIBRC banned list)
